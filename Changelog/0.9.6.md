# Changelog / 更新日志

## 0.9.6 (2026-07-06)

### 变更
- **音频采集: Orbbec Astra Pro 内置麦克风 → ReSpeaker Mic Array v2.0 (XVF3000)**
  - `voice_capture_node.py`: 新增 `hp_enable` 参数 (bool, 默认 false)，
    XVF3000 板载波束成形+自适应降噪替代软件 HPF
  - `voice_params.yaml`: 适配 ReSpeaker 单声道 beamformed 输入，
    移除 `hp_cutoff` 直配，新增 `hp_enable: false`
  - `setup.py` / `package.xml`: 设备描述更新
- **DOA 声源定位: 新增 `src/voice/voice_doa/` 包**
  - `voice_doa_node.py`: 通过 USB HID 读取 XVF3000 DOA 角度
  - 三个后端按优先级自动选择:
    `pyusb` (vendor control transfer, 最可靠) → `hidapi` → `hidraw`
  - 话题: `/voice/doa_angle` (Float32), `/voice/doa_direction` (String)
  - 12 扇区 30° 分辨率，可配置 poll_rate/angle_offset/VID:PID/backend
  - 新增硬件 VAD 发布: 读取 VOICEACTIVITY 寄存器，发布 `/voice/vad_hw`
  - 新增 LED 灯环控制: `pixel_ring` 库，初始化后自动 trace 模式
  - 新增参数调优 service: `/voice/respeaker_set_param` 和 `get_param`，
    可通过 `ros2 service call` 读写任意 XVF3000 寄存器 (HPF/AGC/AEC/…)
  - 新增 `/voice/status_led` 话题: 外部控制 LED 颜色
- **VAD: 改用 XVF3000 硬件 VAD**（彻底移除 WebRTC VAD）
  - `voice_vad_node.py`: 简化，只读取 `/voice/vad_hw` 硬件 VAD 信号，
    同步缓冲音频并发布完整语音片断
  - `voice_params.yaml`: 移除 `vad_source`/`vad_mode`/`min_energy` 参数
  - `package.xml`: 移除 webrtcvad 依赖
  - 文档中 VAD 参数调优章节移除
- **声源跟踪: 新增 `jetauto_app/servo_tracker.py`**
  - 订阅 DOA 角度 → 驱动云台舵机转向声源
  - 可配置舵机 ID / center/range / 映射角度范围 / 超时回中
  - 注册 entry_point: `servo_tracker`
- **唤醒词多模态反馈: `voice_feedback` 重写**
  - 唤醒后同时触发: 扬声器音效 + STM32 蜂鸣器 (低频安静) + LED 灯环 (青色闪亮)
  - 新增 buzzer_freq/buzzer_on_time/led_r/g/b/a/duration 参数
  - 蜂鸣器默认 800Hz (远离谐振点，比默认 1900 安静)
  - 新增 `ros_robot_controller_msgs` 依赖
  - `voice_params.yaml`: 新增 voice_feedback 蜂鸣器/LED 参数段
- **驱动与权限: 新增 ReSpeaker HID udev 规则**
  - `scripts/99-respeaker.rules`: 允许普通用户访问 XVF3000 HID 设备
- **启动文件更新**
  - `hijetson_voice.launch.py`: 加入 voice_doa 节点
  - `hijetson_all.launch.py`: 加入 voice_doa + servo_tracker
