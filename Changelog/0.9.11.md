# Changelog / 更新日志

## 0.9.11 (2026-10-13)

### 新增
- **`hijetson_bringup` 启动包**：原来裸放在 `src/launch/` + `src/config/` 的 launch 文件与参数 yaml 收进一个 ament_python 包
  - 动机：`src/launch/` 不是 ROS 包，CI 只打包 `install/`，所以**容器里根本没有这些 launch 文件**，语音管线在容器里无法 `ros2 launch`
  - 现在装到 `install/hijetson_bringup/share/hijetson_bringup/{launch,config}/`，容器内 `ros2 launch hijetson_bringup hijetson_voice.launch.py`
  - 三个 launch 都改用 `get_package_share_directory('hijetson_bringup')` 定位 `config/voice_params.yaml`（原来靠 `../config/` 相对路径，离开源码目录就失效）

### 修复
- **9 个 python 包的节点可执行文件装错位置**：`voice_asr / voice_capture / voice_doa / voice_executor / voice_feedback / voice_hotword / voice_vad / depth_processor / fusion_node` 的 `setup.cfg` 缺 `[install] install_scripts=$base/lib/<pkg>`，导致可执行文件装到 `install/<pkg>/bin/`，`ros2 run <pkg> <node>` 报 "No executable found"（`ros2 launch` 靠 PATH 侥幸能用）
  - 补齐后落到规范的 `install/<pkg>/lib/<pkg>/`，与 JetAuto 侧全部包一致；`voice_feedback` 里 `install-scripts`（连字符）笔误一并修正
- **`hijetson_all.launch.py` / `hijetson_vision.launch.py` 引用了不存在的包**：`image_preprocess`、`object_detection` 从未实现，起全量/视觉必报 package not found。已移除并留 TODO 注释；相机改为 include `jetauto_peripherals/depth_camera.launch.py`，`hijetson_all` 现在真的能"全量启动"

### 变更
- `scripts/start.sh`：从 `sleep infinity` 占位改成真正的容器主进程 —— 准备 ROS 环境 → 等设备就绪 → `exec ros2 launch hijetson_bringup <LAUNCH>`
  - 启动哪个管线只改脚本顶部 `LAUNCH=` 一行，**compose 不掺业务**（compose 只负责跑 `/opt/hijetson/start.sh`）
  - 支持 `HIJETSON_LAUNCH=shell` 临时进容器调试
- `scripts/run_voice.sh / run_all.sh / run_vision.sh`：改为 `hijetson_bringup` launch 的薄封装（原来 run_all/run_vision 手工 `ros2 run` 一长串，其中引用了不存在的包，且与 launch 文件重复维护）
- `scripts/setup_jetson.sh`：标注为"宿主机原生老流程"（JetPack 7 / Ubuntu 24.04 上装不了 Humble，现在推荐容器）；默认切国内镜像源（apt ubuntu-ports + pip 清华，可 `SKIP_MIRROR=1` 跳过）；补装 `libportaudio2/alsa-utils/pyusb/hidapi/pixel-ring`；末尾加 udev 规则安装
- **新增容器配置（放 `scripts/`）**：`scripts/Dockerfile.my-ros`（在 gitea registry 的 `ros:humble-ros-base` 基线上追加语音/USB 运行依赖，国内源）、`scripts/docker-compose.yml`（`/dev:/dev` + `privileged` + host 网络 + `ROS_DOMAIN_ID=42`）

### 验证（Jetson Orin Nano，宿主 JetPack 7 / Ubuntu 24.04）
- 容器内 `colcon build` 全量编译通过；`install/hijetson_bringup/share/hijetson_bringup/{launch,config}` 与 9 个包的 `lib/<pkg>/<node>` 均已就位
- `ros2 launch hijetson_bringup hijetson_voice.launch.py` 在容器里起 8 个节点：capture/vad/hotword/feedback/doa/servo_tracker/executor 正常，`voice_asr` 因容器未装 `whisper`(GPU 批，尚未进镜像) 退出、`voice_hotword` 缺 `vosk` 打警告后降级运行
- 容器内实测硬件：ReSpeaker 采集到真实音频（1s 16kHz 单声道，RMS≈431）、DOA 读出角度、Astra 驱动 `list_devices_node` 认出相机（`2bc5/0403`，SN `17122410834`）
- `/dev:/dev` 生效后容器能看到宿主全部声卡与 `/dev/video*`，`docker exec -it` 交互不受影响
