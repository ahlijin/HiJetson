# Changelog / 更新日志

## 0.9.10 (2026-10-11)

### 修复
- **voice_feedback 唤醒提示音不触发**（`voice_feedback_node.py`）
  - 根因：`9abf6f8` 用 `voice_hotword` 替换 `voice_wake_word` 并删除该包后，`/voice/wake_word` 再无发布者，而 voice_feedback 仍订阅它 → 订阅悬空，唤醒时的提示音/蜂鸣/LED 反馈整条链路失效
  - 改为订阅 hotword 发布的 `/voice/wake`（std_msgs/Bool）：`True`（唤醒）触发，`False`（休眠）直接返回、不反馈
  - 与 voice_asr 门控、jetauto_app/servo_tracker 改用同一信号源，语义一致
  - 验证：my-ros(Humble/aarch64) 容器内 colcon 编译通过（EXIT=0）；真 rclpy + 真 DDS 跨进程发 `Bool` 验证 —— 唤醒触发蜂鸣(800Hz/0.12s)/LED/提示音(0.30s@48k)，休眠静默，`/voice/asr_result` 路径不受影响

### 变更
- **代码来源迁到本地 gitea**：origin = `http://192.168.3.96:3000/legend/HiJetson.git`；子模块 `src/orbbec_ws` 改指 gitea 的 `legend/ros2_astra_camera`（github 与 NAS 均弃用），干净环境下 `clone --recurse-submodules` 可独立拉通
- **文档同步到当前实现**：README / CLAUDE.md 按实际代码重写（语音 8 包：capture/doa/vad/hotword/asr/executor/feedback/msgs；VAD 为 XVF3000 硬件 VAD；唤醒为 Vosk 双唤醒「小车小车 / 小方小方」+ 19 条指令短语；DOA 镜像校准与舵机跟随；视觉标注 `image_preprocess`/`object_detection` 未实现）
- CLAUDE.md 构建段改为开发机 my-ros 容器 + Jetson 原生两套流程
- `scripts/setup_jetson.sh` 的 Astra 驱动改为 git submodule 初始化（原为从 github 克隆到旧布局）

### 注意
- `/voice/state`（hotword 发布）与 `/voice/voice_activity`（voice_vad 发布）当前无订阅方：前者是调试用状态文本，后者是能量 VAD 时代 ASR 门控的遗留，暂保留可 `ros2 topic echo` 观察
- `src/launch/hijetson_all.launch.py` 与 `scripts/run_all.sh` 仍引用未实现的 `image_preprocess`、`object_detection` 包，单独跑全量启动会报找不到可执行文件
