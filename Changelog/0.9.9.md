# Changelog / 更新日志

## 0.9.9 (2026-08-04)

### 新增
- **唤醒词方向锁存** (voice_doa)
  - VAD 上升沿（语音开始瞬间）锁存 DOA，发布新话题 `/voice/doa_locked`
  - 修复首轮语音不触发锁存（`_prev_vad` 初始 False）
- **servo_tracker 唤醒触发模式**
  - 订阅 `/voice/wake`（Bool）替代 `/voice/voice_command`——**移动指令不再触发舵机/旋转**
  - 方向数据优先用 VAD 上升沿锁存值，无锁存时兜底语音期间方向（vad=True 门控）
  - 无语音时 DOA 为漂移噪声，一律不采信
- **声源超出舵机范围（±45°）→ 开环整体旋转**
  - 唤醒时按 DOA 计算最短转角，时长 = 角度/rotate_gain，转完即停
  - 不再依赖 DOA 实时更新（规避无语音时 DOA 冻结导致转不停）
  - 旋转全程舵机不动
- **退出/自动休眠舵机回正**：`/voice/wake=False` → 舵机回 center_pulse(500)、停止旋转
- **DOA 镜像校准**：`angle_offset=270`（拾音器角度递增方向与小车坐标系相反，加法无法表达镜像）
  - 校准后 DOA 为小车坐标系：正前=0 / 右=90 / 左=270 / 后=180
- **rotate_gain 0.3 → 0.6**：唤醒整车旋转速度加倍

### 变更
- `voice_doa_node.py`: pyusb 分支角度公式 `(raw+offset)%360` → `(offset-raw)%360`（镜像）
- `voice_executor_node.py`: SERVO_CMD 修正为 看左边=688 / 看右边=312 / 回正=500（总线舵机反装，旧值 500/2500/1500 超出物理限位 312-688）
- `voice_params.yaml`: servo_tracker `invert=true`、`rotate_gain=0.6`
- **Pi3 侧 odom_publisher**（代码在 HiWonder_JetAuto 仓库）：全向碰撞检测（左/右扇区）+ 旋转堵转检测（IMU）+ angular 限幅 0.5→0.6

### 修复
- 无语音时 DOA 漂移噪声导致唤醒转向乱转/转过头（VAD 门控 + 上升沿锁存）
- 声源方向整体偏差（镜像校准，此前 +90/-90 均无法对齐）
- 唤醒转向方向与显式舵机指令不一致

### 注意
- `twist_to_motor_bridge.py` 首次纳入版本控制（8月1 起存在于工作区并已编译进 install；当前未在 launch 中启用）
