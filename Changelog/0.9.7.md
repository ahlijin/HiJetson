# Changelog / 更新日志

## 0.9.7 (2026-07-28)

### 新增
- **voice_hotword: 双唤醒词 + Vosk 语法模式**
  - "小车小车" → Vosk 语法匹配模式（19 短语，CPU）
  - "小方小方" → ASR 直通模式（跳过 Vosk，直接 Whisper 转录）
  - Vosk 改为 Grammar 模式：字符空格分隔 + `[unk]` silence 吸收
  - "向前"/"向后" 作为 "前进"/"后退" 同义短语
  - "退出" 替代"休眠"，Vosk/ASR 模式均有效
  - 不同唤醒词不同蜂鸣（800Hz 单次 vs 1000+800Hz 双响）
  - Epoch 隔离机制：ASR 轮次标记，防慢结果跨轮污染
- **voice_vad: 前缀环形缓冲**
  - `prefix_frames: 10`（~300ms 回看），解决 VAD 首字裁切

### 变更
- Vosk 模式下无匹配不再走 ASR 兜底，改为静默忽略
- servo_tracker 角度范围 ±90° → ±45°（center_pulse ± range_pulse/2）
- `clip_save_enabled` 默认 false（调试代码保留）

### 修复
- Vosk 语法模式中文需空格分隔，避免全部识别为"向右"
- 蜂鸣不重复（从 `_wake_up` 移到各自回调）
- ASR 模式中说"退出"正确进入休眠
- ASR 结果跨轮污染（epoch 校验丢弃过期结果）
