# Changelog / 更新日志

## 0.9.8 (2026-07-29)

### 新增
- **voice_executor 包**: 语音指令执行器
  - 订阅 `/voice/voice_command`，解析短语到电机/舵机/蜂鸣动作
  - 前进/后退/向左/向右/左转/右转/停止 → Twist `/cmd_vel`（0.5s 自动停）
  - 看左边/看右边/回正 → ServosPosition `/servo_controller`
  - 蜂鸣/LED 反馈
- **servo_tracker: 语音触发旋转**
  - 收到语音指令时，根据最新 DOA 方向转动舵机朝向声源
  - 舵机达到机械限位后自动发 `cmd_vel` 转动小车
  - 不再连续跟踪 DOA（避免每个声音都转）
  - 旋转自动停止定时器
- **DOA pyusb 不踢 ALSA**
  - 不再 detach 音频内核驱动，录音和 DOA 可同时工作
  - 靠 udev `MODE=0666` 权限直接做 vendor control transfer

### 变更
- `voice_params.yaml`: DOA backend `hidraw` → `pyusb`
- `hijetson_voice.launch.py`: 加入 servo_tracker 和 voice_executor 节点

### 修复
- servo_tracker `AssertionError: position must be float`（int→float）
- DOA 节点 pyusb detach 导致 ALSA 录音断连
